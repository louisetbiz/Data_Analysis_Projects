# mental_health_tech_analysis
Data analysis about mental health in tech professionals

# This project analyzes mental health trends among technology workers using survey data. The objective is to identify workplace and demographic factors associated with mental health outcomes and provide recommendations for employers.

Tools Used
SQL (Big Query)
DATA STUDIO

# Dataset
https://www.kaggle.com/datasets/osmi/mental-health-in-tech-survey

# Key Questions

Which demographic groups report the highest mental health challenges?
Does company size influence mental health support?
Are remote workers more likely to seek treatment?
How does workplace support affect outcomes?

# Key Findings
Mental health concerns are present across all age groups.
Larger organizations report a substantial number of mental health concerns.
Many employees are unaware of available mental health benefits.
A significant gap exists between experiencing issues and seeking help.

# Recomendations
Improve communication around benefits.
Increase awareness campaigns.
Encourage help-seeking behavior.
Train managers to recognize early signs of burnout.
